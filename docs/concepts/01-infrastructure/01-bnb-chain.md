# 基础设施 — BNB Chain

> Predict.fun 的底层公链：BNB Smart Chain（Chain ID 56）

---

## 为什么选 BNB Chain

| 特性 | 说明 |
|------|------|
| 低 Gas / 高吞吐 | 适合高频小额预测交易 |
| EVM 兼容 | 复用 Gnosis CTF、UMA 适配器等成熟框架 |
| Binance 生态 | 与 Binance Wallet、Venus 借贷深度协同 |
| 稳定币 + DeFi | USDT 流动性 + Venus 借贷市场支撑「生息抵押」 |
| 亚洲用户 | 主基础设施部署东京（ap-northeast-1），亚洲优先 |

---
