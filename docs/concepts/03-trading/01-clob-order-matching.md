# 订单撮合 — 链下 CLOB + 链上原子结算

> Predict.fun 的混合架构：链下高效撮合，链上可信结算（与 Polymarket 同源）

---

## 什么是 CLOB

中央限价订单簿（CLOB）是核心交易引擎，采用链下撮合 + 链上结算：

```
用户签名订单 → 链下 CLOB 撮合 → 链上 CTFExchange 原子结算
```

---

## 为什么不全链上

| 方案 | 优点 | 缺点 |
|------|------|------|
| 纯链上 | 完全去中心化 | 挂单/撤单都需 Gas，延迟高 |
| 纯链下 | 快、零 Gas | 资产托管风险 |
| 链下撮合 + 链上结算 ✅ | 快 + 资产安全 | 撮合环节需信任平台 |

撮合成功后，匹配订单对提交到 BNB Chain 上的 CTFExchange，原子执行（全成或全回滚）。

---

## 注意事项

- 客户端不活跃时，平台可能自动清理该 session 挂单。
- API 有频率限制（默认 240 req/min）。
- 生产环境需实现 WebSocket 心跳保活。
